About this project

Built for curious minds

PeriodicX is an educational reference built around the standard IUPAC periodic table. Element data — mass, electron configuration, melting and boiling points, and more — is drawn from public reference sources. Where a superheavy element's properties have never actually been measured (many transactinides exist for only fractions of a second), we say so rather than inventing numbers.
